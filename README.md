# مراجعة السلامة المهنية — OSH

موقع مراجعة static لمادة **السلامة والصحة المهنية**. يعمل مباشرة في المتصفح ولا يحتاج خادمًا أو قاعدة بيانات.

## المحتوى

- شرح مراجعة عربي مبني على المحاضرات الست المرفوعة فقط.
- ملفات PDF الأصلية مضمنة في مجلد `sources/` وتُفتح من داخل الموقع.
- بنك الأسئلة من ملف `osh-quiz.html` كما ورد فيه: **61 سؤالًا فعليًا**:
  - محاضرة 1: 12
  - محاضرة 2: 12
  - محاضرة 3: 12
  - محاضرة 5: 12
  - LOTO: 13
- المحاضرة 6 متاحة كشرح ومراجعة شاملة. لا توجد لها مجموعة أسئلة مستقلة في ملف الأسئلة المرفوع، لذلك لم تُنشأ أسئلة جديدة.

## المزايا

- وضع مذاكرة بتصحيح فوري وإجابة من بنك الأسئلة ورابط للمرجع.
- وضع اختبار مع خلط اختياري للأسئلة والاختيارات ومؤقت اختياري.
- لوحة تقدم، وبحث وفلاتر لحالات: لم تُحل / صحيحة / تحتاج مراجعة.
- مراجعة الأخطاء والأسئلة غير المحلولة.
- حفظ التقدم محليًا في المتصفح، مع تصدير واستيراد JSON ومسح آمن.
- وضع ليلي، واجهة عربية متجاوبة للهواتف، وتنقل واضح وإتاحة لوحة المفاتيح.

## التشغيل محليًا

افتح `index.html` مباشرة، أو شغّل خادمًا محليًا داخل هذا المجلد:

```powershell
py -m http.server 8000
```

ثم افتح:

```
http://localhost:8000
```

## الرفع على GitHub Pages

1. أنشئ مستودع GitHub جديدًا، مثل `industrial-safety-review`.
2. ارفع **كل محتويات هذا المجلد** إلى جذر المستودع، بما فيها مجلد `sources`.
3. في GitHub افتح: **Settings → Pages**.
4. تحت **Build and deployment** اختر:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/(root)**
5. اضغط **Save**. يظهر رابط النشر في صفحة Pages خلال دقائق.

لا تستخدم مسار `/docs` إلا إذا نقلت الملفات إليه، ولا تحذف مجلد `sources` لأن روابط المحاضرات تعتمد عليه.

## الملفات

- `index.html`: بنية الموقع والشرح.
- `styles.css`: التصميم والوضع الليلي والتجاوب.
- `data.js`: بنك الأسئلة المرفوع.
- `app.js`: التفاعل والحفظ والاختبارات.
- `sources/`: المحاضرات الأصلية بصيغة PDF.

## ملاحظة المصدر

الموقع لا يضيف حقائق دراسية أو أسئلة من خارج الملفات المرفوعة. الإجابة المعروضة في بنك الأسئلة هي الإجابة المحددة في ملف `osh-quiz.html`، والشرح المختصر يشير إلى ملف المحاضرة الأصلي.
